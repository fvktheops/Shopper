A modern platform for code collaboration — LUVORA

Create repositories, open issues, review code, and collaborate in real time. LUVORA is a lightweight GitHub-like platform you can self-host and extend.

Open LUVORA View project on GitHub
Repositories
Create and host Git repositories with full commit history and a browser-based code view.
Issues & PRs
Track bugs, requests, and collaborate on pull requests with inline comments and reviews.
Real-time
Live notifications and comment streaming using WebSockets (Socket.io + Redis adapter).
Extensible
Add CI, webhooks, and integrations. Designed for self-hosting and cloud deployment behind Cloudflare.

Quick start

  1. Sign up and create an account
  2. Create your first repository
  3. Clone using the provided clone URL
  4. Open issues and collaborate
Run locally
docker compose up --build
